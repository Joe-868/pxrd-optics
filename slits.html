General XRD optics

Fixed, programmable and automatic DS

A fixed DS keeps one opening, so the irradiated length changes with angle; a programmable DS in automatic mode keeps it near a chosen value. A programmable anti-scatter slit can follow it.

Every programmable slit has a largest opening; beyond the angle where it is reached, L falls again. Variable-opening data need an intensity correction before comparison with fixed-slit data, which instrument software normally applies.

Geometric model

Point source at radius R, flat sample on the axis, straight rays, ω = 2θ/2. L(α) = R/(sin ω / tan(α/2) + cos ω) + R/(sin ω / tan(α/2) − cos ω) rises monotonically with α, so α is solved numerically for the target L. Manufacturers may use their own relation; see the instrument-specific calculators.

Matching the anti-scatter slit

The DS sets what is irradiated, the anti-scatter slit what the detector sees; only the overlap is measured.

The anti-scatter slit cuts air scatter and scatter from outside the measured area, but it cannot remove a reflection from an irradiated holder. Malvern Panalytical calls the programmable version PASS.
