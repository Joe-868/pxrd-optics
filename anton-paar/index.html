Instrument-specific configuration

Anton Paar XRDynamic 500

Estimate the illuminated width from the radius, the incident Soller slit and the mask, or choose a mask for a target width.

  • XRDynamic 500 · line focus
  • R = 360 or 400 mm
  • Incident Soller slit
  • Beam mask < 14 mm
Model applicabilityConfiguration, reference sources and limitations
Applicable configuration
Anton Paar XRDynamic 500, line focus, goniometer radius 360 mm or 400 mm, beam mask opening below 14 mm (instrument range 0 to about 13 mm).
Optical components required
An incident Soller slit with acceptance angle 0.05, 0.025 or 0.0125 rad, and a beam mask downstream of it.
Source of reference parameters
Manufacturer-supplied technical guidance and elementary geometrical relationships. The mask position (242.4 mm term) is an instrument-specific parameter from that guidance.
Assumptions and limitations
  • W is a geometric estimate of the full illuminated width (an envelope), not a FWHM or a measured profile.
  • Removing the Soller slit is not the same as α = 0; α = 0 is the ideal parallel-ray limit. Without a Soller slit this model does not apply.
  • Weak tails beyond W are not described, so the result cannot by itself guarantee clearance from a holder edge.

What this calculation does and does not cover

  1. It is a geometric estimate of the full illuminated width, valid for line focus and a mask opening below 14 mm.
  2. It applies when an incident Soller slit is installed; α is the acceptance angle of that slit.
  3. Removing the Soller slit is not α = 0, the ideal parallel-ray limit; without a Soller slit this model does not apply.
  4. It does not describe the intensity distribution or weak tails beyond W, so it cannot by itself guarantee clearance from a holder edge.
  5. For capillary transmission, the mask mainly limits the illuminated length along the capillary; keep W within the sample-filled section.
